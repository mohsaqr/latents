latents verification matrix

Package 1.0.0. Built from saved evidence on 2026-10-29; nothing was refitted. 35,806 current checks (3,446,037 values) against references other than latents itself.

A check is one harness quantity (a whole output column counts once; values counts every number inside it) or one testthat expectation. Current means produced on 2026-10-28 or 2026-10-29 by the R code shipped in 0.98.0 and 0.98.1 (unchanged in 1.0.0). Results from 0.96.1 (2026-10-20) are shown in grey and do not count toward strength.

Legend

Strength
One + per source: an independent program or package (another R package, Mplus, Latent GOLD, Stata, Python) whose results agree on the current code for a model with two or more classes. One P per published paper whose printed numbers are reproduced. ++++ PP is four sources and two papers. Colour: 0 no source, + one, ++ two, +++ three or more.
Not counted
Agreement on a one-class reduction only (one class equals lm(), glm.nb(), polr(), lme4, a linear mixed model), shown as "(1 class)"; our own independent code (numDeriv, dense likelihoods, the kits' reference implementations); internal checks (invariance, seed stability, refusal parity); results last run under 0.96.1.
Sources, papers
The number of + and of P.
Datasets
Distinct datasets on which the function was compared with a source or a paper on current code, for models with two or more classes: the harness's datasets, the kits' datasets (kit-datasets.csv) and the simulated datasets of the testthat kits that the other program ran (test-datasets.csv). A dataset used by several kits counts once. Tests that build their own small data inline are not counted, so this is a lower bound.
Checks passed
Current checks against every reference other than latents itself: one harness quantity (a whole output column), one kit quantity or one testthat expectation. Values counts the numbers inside the harness checks.
Failed
Current checks that disagree without a registered, explained difference (each kit's known-differences.csv).
Grid cells
bold: current checks on mixtures; (1 class): one-class reductions only; grey italic: last run under 0.96.1 or no saved result; candidate: found, not yet wired in; *: a test that checks several functions or references at once (counted once in each function's total).
