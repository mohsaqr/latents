## Legend

- **Strength**: one `+` per *source*, an independent program or package (another R package, Mplus, Latent GOLD, Stata, Python) whose results agree on the current code for a model with two or more classes; one `P` per published paper whose printed numbers are reproduced. `++++ PP` is four sources and two papers.
- **Not counted**: agreement on one-class reductions only (marked "(1 class)"), our own independent code, component checks, internal checks, stale results, and sources with failed or incomplete tests.
- **Datasets**: distinct datasets on which the function was compared with a source or a paper on current code, for models with two or more classes (the harness, the sweep, the kits and the testthat simulation kits that the other program ran). A dataset used by several kits counts once; tests with small inline data are not counted, so this is a lower bound.
- **Current**: both the complete runtime-source manifest and the result-file hash match their evidence sidecar. Historical 1.0.0 evidence uses an explicitly labelled retrospective source-equivalence attestation; it is not a new run.
- **Checks**: current harness quantities, kit quantities, argument-sweep checks and passed testthat expectations against every reference other than latents itself. **Failed**: checks that disagree without a registered, explained difference, plus test errors. Skips are incomplete and earn no source credit.
