Data files, downloaded 2026-11-14 (md5 of every file in DATA.md5):

lca1.dat: https://stats.oarc.ucla.edu/wp-content/uploads/2016/02/lca1.dat, linked from
  https://stats.oarc.ucla.edu/sas/dae/latent-class-analysis/ (the same file as
  mplus-published/data/lca1.dat, md5 8fef40402ae1d59437e6be1f522452a3).
page16.sas7bdat, page33.sas7bdat, page47.sas7bdat:
  https://stats.oarc.ucla.edu/wp-content/uploads/2016/02/<name>.sas7bdat, linked from
  https://stats.oarc.ucla.edu/sas/examples/lca-mccutcheon/latent-class-analysis-by-allan-l-mccutcheon/
  mccutcheon-<name>.csv hold the same tables, written by
    d <- as.data.frame(haven::read_sas("<name>.sas7bdat")); d[] <- lapply(d, as.integer)
    utils::write.csv(d, "mccutcheon-<name>.csv", row.names = FALSE)
  (haven 2.5.5; every column is a whole number).
help.csv: https://nhorton.people.amherst.edu/sasr2/datasets/help.csv, the HELP data of
  Kleinman and Horton, SAS and R (the data set of Example 8.21,
  https://sas-and-r.blogspot.com/2011/01/example-821-latent-class-analysis.html).
galaxies.txt: the 82 velocities of the DATA step in SAS/STAT 14.2 User's Guide, chapter 40
  (The FMM Procedure), "Looking for Multiple Modes: Are Galaxies Clustered?",
  https://support.sas.com/documentation/onlinedoc/stat/142/fmm.pdf, transcribed. It
  differs from MASS::galaxies in one value: the 78th (sorted) is 26960 here and 26690 in
  MASS, whose help page notes that 26960 is the correct value.
yeast.csv: Table 40.1 of the same chapter ("Student"'s yeast cell counts), transcribed.

The printed SAS values in compare-functions.R are copied from the same pages and the
same PDF (accessed 2026-11-14).
