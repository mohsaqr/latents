# Print a pooled multiply imputed fit

Print a pooled multiply imputed fit

## Usage

``` r
# S3 method for class 'latents_pooled'
print(x, digits = 4L, rows = 20L, ...)
```

## Arguments

- x:

  A `latents_pooled` object.

- digits:

  Significant digits.

- rows:

  How many rows of the pooled table to show.

- ...:

  Unused.

## Value

`x`, invisibly. Called for the side effect of printing the model, the
number of imputations and the pooled table.
