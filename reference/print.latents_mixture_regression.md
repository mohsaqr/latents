# Print a mixture-of-regressions fit

Print a mixture-of-regressions fit

## Usage

``` r
# S3 method for class 'latents_mixture_regression'
print(x, digits = 4L, ...)
```

## Arguments

- x:

  A fit from
  [`mixture_regression()`](https://pak.dynasite.org/latents/reference/mixture_regression.md).

- digits:

  Significant digits.

- ...:

  Unused.

## Value

`x`, invisibly.
