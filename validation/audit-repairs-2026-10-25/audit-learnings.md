# Audit lessons — 2026-10-26

- [source versus installed package]: the ordinary installed library was 0.95.1 while source was 0.97.1. Socket workers need a fresh temporary installation through R_LIBS; loading source in the parent alone does not establish worker identity.
- [matching BLAS]: a reference-BLAS parent and Accelerate socket workers can differ by one ULP. Exact parallel parity must use the same BLAS; test real forks separately under the reference BLAS because Accelerate is unsafe after fork.
- [categorical arithmetic]: an unnecessary row shift can perturb EM stopping or tied-start selection despite algebraic equivalence. Preserve ordinary categorical arithmetic when stabilizing unrelated Gaussian or ordinal/count blocks.
- [alignment versus objective identity]: CSV roundtrips need actual base-R serialization matching, with collisions refused. Keep strict fitted-data identity for objective-sensitive inference; do not replace it with relative numeric tolerance.
- [class signatures]: class means alone cannot align equal-mean classes with different Gaussian covariance or negative-binomial dispersion. Include spread and correlation features, using finite transforms at zero count variance.
- [numerical coordinates]: large predictor origins and outcome-unit changes need centered, scaled optimization and a consistent map back to natural parameters. At origins around 1e12, raw intercept reconstruction still has finite-double cancellation.
- [convergence evidence]: a per-iteration likelihood tolerance does not bound the remaining likelihood gap on a flat ridge or establish a global maximum. Retain default-fit diagnostics when a declared validation recipe uses tighter controls or more than one search policy.
- [independent numerical oracles]: the equal-variance ML three-step counterexample required checking likelihood and covariance independently. Declare numDeriv as an optional test dependency when tests call it directly.
- [RNG scope]: explicit seeds can restore the exposed .Random.seed; base R does not expose the Box-Muller cached normal. A NULL seed intentionally advances the caller stream, so universal RNG-restoration claims are inaccurate.
- [audit counts]: distinguish committed source counts, named definitions, executed test assertions, external quantity comparisons and historical study outputs. Passing one suite does not establish another suite's results or universal equivalence.
- [reference optimizer integrity]: retain parameters, objective and posteriors from the same best iterate, including the starting state. A negative gain cannot by itself establish convergence; the joint-item reference reached a nonnegative zero gain after continuing past tiny decreases.
- [comparator budgets]: a discrepancy can come from the external comparator's iteration cap. Preserve its original fit and use a declared uniform verification budget; the poLCA counterexample needed 56,767 iterations rather than 20,000, with seeds, starts and tolerance unchanged.
- [result consolidation]: rerun complete affected files after validation-only fixes and replace their complete result rows in the final ledger. Preserve the original failures, prove unchanged dependencies, and count setup warnings separately from in-test warnings.
- [repair report precision]: the reader-facing repair report maps 53 ledger groups to 41 entries. Report mean errors in standard-error units separately from relative SE error; distinguish direct-helper priors from fitted priors, pre-fork checks from pre-side-effect checks, and sample counts under both drop_empty policies.
- [portable audit handoff]: root HANDOFF.md, CHANGES.md and LEARNINGS.md are intentionally ignored, including same-basename copies on this case-insensitive checkout. Audit-prefixed portable documents keep report links usable without changing the local-session ignore policy.
- [staged whitespace]: an unstaged diff check omits newly untracked tests. Check the staged index before publication; preserve byte-hashed raw logs, and prove parsed R expressions unchanged when trimming a fixture.
